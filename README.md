# Питомник декоративных растений «ДарЛес» — сайт-витрина

Статический сайт-витрина (без корзины и оплаты) для питомника «ДарЛес», Крым,
с. Давыдово, трасса Донское — Кленовка.

**Стек:** чистые HTML + CSS + JavaScript + небольшой PHP-API для хостинга.
Без сборки, без npm. Сайт работает и как статика (открыть `index.html`),
и на PHP-хостинге — тогда админ-панель сохраняет каталог, фото и ключ ИИ
напрямую в файлы хостинга (GitHub не нужен).

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: шапка с контактами, Hero с логотипом, блок «Что такое ДарЛес?», карусель фото питомника, кнопка «Каталог» + карусель товаров, круглые кнопки категорий, тёмный подвал с соцсетями |
| `catalog.html` | Каталог с вкладками «Хвойные / Лиственные / Многолетние», поиском и сортировкой по цене |
| `product.html` | Страница растения: галерея, название, цена, развёрнутое описание, кнопки «Связаться» |
| `admin.html` | Админ-панель (открытый доступ, без пароля): добавление/изменение/удаление растений, фото drag&drop, редактор фона и выравнивания, ИИ-определение растения по фото. Все правки сохраняются на сервере хостинга |

## Что взято у конкурентов (итоги анализа)

Перед вёрсткой были проанализированы питомники «Добрый Жук», «Суланж»,
«Ренессанс», «САВЛЕС», «Ветка» и «Александровский сад». На сайт перенесены
лучшие решения:

1. **Карточка товара с ценой и короткой подписью** («Добрый Жук») — цена видна
   сразу, без перехода на страницу товара.
2. **Блок масштаба и надёжности** («Суланж») — цифры 15 га / 400 000+ растений /
   350+ сортов на главной вызывают доверие.
3. **Чистая структура каталога с вкладками-категориями** («САВЛЕС»,
   «Ренессанс») — три вкладки с иконками + поиск и сортировка.
4. **Фото-карусели с автолистанием** («Ветка») — лёгкий современный ритм главной.
5. **Круглые кнопки-категории** («Александровский сад») — быстрый вход в нужный
   раздел каталога прямо с главной.

Свой вклад поверх анализа: умный помощник по сайту, админ-панель и фоторедактор.

## Как добавляются растения (сайт на хостинге)

Через **админ-панель** (`admin.html`): фото перетаскиванием (можно вставить
Ctrl+V), поля — как в форме, кнопка «Опубликовать на сайт». Панель сохраняет
всё прямо в файлы хостинга:

1. Фото → `images/catalog/<id>.jpg` (через `api/upload.php`),
2. Каталог → `data/catalog.json` (через `api/catalog.php`),
3. Страницы сайта читают `data/catalog.json` и сразу показывают изменения.

Есть также: ИИ-определение растения по фото (прокси `api/ai.php` — ключ на
сервере, наружу отдаётся только маска), кнопка «Скачать каталог (JSON)» —
резервная копия данных.

## Локальный запуск

```bash
git clone https://github.com/samagon90/lera-project.git
cd lera-project
php -S 0.0.0.0:3000     # серверный режим: админ-панель сохраняет данные
# откройте http://localhost:3000
```

Без PHP — `python3 -m http.server 3000` или двойной клик по `index.html`:
сайт работает в статическом режиме, админ-панель показывает «статический
режим» (правки можно скачать файлом `darles-catalog.json`).

## Перенос на хостинг (webnames.ru)

1. Скачайте архив `darles-site.zip` (он же лежит в корне репозитория).
2. В панели хостинга: «WWW-домены» → создайте домен, дождитесь ~30 минут.
3. «Менеджер файлов» → зайдите в `/www/<ваш-домен>/` → загрузите
   `darles-site.zip` → распакуйте → удалите архив.
4. Откройте домен в браузере. PHP на хостинге уже есть — серверный режим
   включён автоматически, GitHub больше нигде не нужен.
5. В админ-панели (`/admin.html`) → «Настройки» → вставьте ключ OpenAI —
   ИИ-помощник заработает (запрос идёт через сервер, CORS/«failed to fetch»
   исключено; если сервер не видит api.openai.com — укажите прокси в поле
   «Свой адрес API»).
